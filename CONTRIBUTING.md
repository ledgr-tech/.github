# Como contribuir

## Branches

- `main` — protegida, só recebe merge via Pull Request.
- `feature/<slug>`, `fix/<slug>`, `chore/<slug>`, `docs/<slug>` — branches de trabalho.

## Commits

Seguimos Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`.

## Pull Requests

1. Abra a branch a partir de `main`.
2. Abra o PR cedo, mesmo em rascunho, se ajudar a alinhar com o time.
3. Peça revisão de pelo menos um sócio antes do merge.
4. Prefira squash merge para manter o histórico limpo.

## Dúvidas e decisões

Use Discussions no repositório `averilla-docs` para decisões de produto/arquitetura que não são código nem issue.
